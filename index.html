サービス利用規約 ＆ プライバシーポリシー

雑談サーバーBotの利用条件、ルール、認証方法、および個人情報の取り扱い（プライバシーポリシー）を定めるものです。ユーザーは本規約に同意したものとみなします。

第1条（サーバー内のルール）

  1. この雑談ルーム内で住所や個人情報を晒さないでください（タイムアウトする可能性があります）。
  2. 不適切なメッセージ、画像、動画などは送らないでください（最悪バンする可能性があります）。
  3. もし不適切なメッセージ、個人情報などを晒していたらすぐに管理者にお知らせください（バンなどの処置をします）。
  4. 荒らしのチャンネルは荒らしてもよろしいですが、過度なものなどは削除いたしますのでご注意ください。

第2条（Botについて）

  1. このBotは認証などのお手伝いをしています。
  2. もし主がオフラインの場合はBotもオフラインになる場合もあります。
  3. このBotを別のサーバーに登録しても使用できないのでご注意ください。
  4. このbotは24時間稼働ではありません。

第3条（@everyone や @here などの使用について）

メンションをしてもよろしいですが、関係ない文章にメンションしたり、何回もメンションする場合は、バンやキックやタイムアウトなどを行う可能性があるのでご注意ください。

第4条（プライバシーポリシー - データの取り扱い）

本Botは、Discordが提供するAPIを利用して運営されています。ユーザーのデータは以下のように適切に取り扱います。

  • 取得するデータ： Botの機能（認証や管理など）を動作させるために必要な、DiscordのユーザーID、サーバーID、および必要最低限のデータのみを取得します。
  • データの利用目的： 取得したデータは、Botによる認証機能の提供およびサーバーの正常な管理のためにのみ利用します。
  • データの第三者提供： 法令に基づく場合を除き、取得したデータを第三者に提供することはありません。

第5条（免責事項）

  • 管理者は、本Botの利用に関してユーザーに生じたあらゆる損害について、一切の責任を負いません。
